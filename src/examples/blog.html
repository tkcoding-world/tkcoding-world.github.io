用 CSS 变量构建一个可切换的主题系统

TK tkcoding · 2026 年 10 月 22 日 · 阅读约 5 分钟

过去，给网站换主题色往往意味着重新编译 Sass 或维护多份样式表。如今借助 CSS 自定义属性 与 color-mix()，只需一个变量就能驱动整套配色。

一、只定义一个主色

把主色声明在根元素上，其余色阶全部由它推导：

:root {
  --tk-primary: #e11d48;
  --tk-primary-soft: color-mix(in oklab, var(--tk-primary) 13%, transparent);
  --tk-primary-hover: color-mix(in oklab, var(--tk-primary), #000 14%);
}
好的设计系统，应当让「改一处」就能「变全局」。

二、按页面覆盖

每个页面只要在 <html> 上写入不同的值，就拥有了独立的品牌色。本页就使用了 data-primary="rose"，并顺手把字体换成了衬线体。

小技巧：派生变量必须和主色声明在同一个元素上（或其子元素中重新声明），否则会沿用父级计算好的旧值。

三、别忘了暗色模式

  • 使用 prefers-color-scheme 跟随系统；
  • 提供 data-mode 属性允许用户手动覆盖；
  • 把选择保存在 localStorage 中。
