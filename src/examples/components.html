需要构建工具吗？

不需要，直接引入 CSS 文件即可。

支持哪些浏览器？

所有支持 color-mix() 的现代浏览器（Chrome 111+、Safari 16.2+、Firefox 113+）。

可以只用 CSS 吗？

可以，JS 仅用于标签页、对话框、导航折叠等交互。

<div class="tabs"><div class="tab-list"><button class="tab" data-tab="id1">…</div><div class="tab-panel" id="id1">…</div></div>
<details class="accordion"><summary>标题</summary><p>内容</p></details>
